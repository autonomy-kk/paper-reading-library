# 纸间阅读 · 在线书库

中外经典的版本化静态目录与分章正文。现有53本：23本中文经典、29本外国经典英文版，以及《茶花女》林纾、王寿昌文言旧译。英文原著与历史英译本均明确标注英文，不冒充中文译本。正文不含AI生成、改写或补全。

每本来源及完整许可见 catalog.json 和 LICENSES/。古登堡标记的美国公版不代表所有地区所有版本均无版权，现代译注不在此库中。

中文旧译来源于维基文库固定修订，保留原作者、译者、编辑历史和 CC BY-SA 4.0 署名及许可链接。原稿保留繁体，应用的繁简转换只影响显示。

更新方式：在应用工作区研究目录中的 build_library.py、build_additions.py 维护已审核书目，生成文件后运行 validate_library.py，再提交本仓库。外文文本入口与原章序针对固定上游版本核实，重复目录和出版信息从阅读正文分离，保留在来源文件中。读者刷新书库即可取得新目录。

本仓库不接收阅读进度、收藏或其他用户数据。
